# Portfólio Profissional — Cristian Souza

Portfólio online de **Cristian Souza**, desenvolvido para apresentar soluções digitais que ajudam empresas a gerar autoridade, atrair clientes e organizar a operação.

O site destaca serviços de criação de sites, sistemas sob medida e agentes de IA para atendimento no WhatsApp, com uma comunicação simples e voltada a resultados de negócio.

## Serviços apresentados

- **Sites que vendem:** páginas profissionais, responsivas e com chamadas para ação.
- **Agentes de IA para WhatsApp:** atendimento automatizado para responder clientes, captar oportunidades e apoiar agendamentos.
- **Sistemas sob medida:** soluções para centralizar agenda, clientes, pedidos e processos internos.

## Conteúdo do portfólio

- Apresentação profissional e proposta de valor;
- Comparativo entre desafios comuns e resultados esperados;
- Serviços oferecidos;
- Projetos demonstrativos para barbearia, clínica e advocacia;
- Processo de trabalho, do contato à entrega;
- Seção sobre o profissional e canais de contato.

## Tecnologias

O projeto é uma página estática, sem dependências ou etapa de build:

- HTML5;
- CSS3 responsivo;
- Google Fonts (`Bricolage Grotesque` e `Manrope`);
- Integração com WhatsApp via links `wa.me`.

## Como visualizar

Abra o arquivo [index.html](./index.html) diretamente no navegador. Não é necessário instalar dependências.
